# Demo guide

1. Start API and frontend using the README instructions.
2. Open the frontend and choose **Run Section 479 screening** on the synthetic case.
3. Review the threshold, factual inputs and human-review notes.
4. Use **Prepare draft** to create an in-memory preparation record. The workflow requires acknowledgement that an authorised human will verify the inputs.

Every record shown is DEMO DATA. The draft is not persisted and is not a filed application.
